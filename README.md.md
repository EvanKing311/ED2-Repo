# Read Me
## Files directory
1. ESP32 Code -- firmware for the 2 esp32's
2. Feedback Documentation -- Original files from Feed back for the pendulum.  includes schematics.
3. Kicad -- files for the PCB
4. MATLAB -- simulink models converted for the raspberry pi
5. picamera -- Files on the pi that is used to make the video sent to the server.
6. picontrol -- Dac_daemon.py that monitors for button presses and executes the simulink models
7. simulink-param-retrieval -- Files for the simulink conversion to gt the parameters from the params.json file into the simulink model running on the pi
8. Webinterface -- django website interface for sciencelabtoyou.com
